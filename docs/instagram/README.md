- [Удаление данных](https://n8n.telegrambotsforeveryone.duckdns.org/instagram/data-deletion) — `data-deletion.html`.

Адреса сохранены в основных настройках приложения Meta **Biomozg Automation**, ID **1481649887194895**. Приложение опубликовано. Живой тест доставки обычному посетителю проверяется отдельно от публикации и статуса API.

Страницы не содержат скриптов, форм, рекламной аналитики и ключей. Контакт для вопросов и удаления — Direct **@biomozg**. Запросы проверяет человек; сообщение «стоп» прекращает автоответы, но не удаляет данные.

## Размещение

Публичные файлы сервера: `/srv/biomozg-instagram/public/privacy.html` и `/srv/biomozg-instagram/public/data-deletion.html`. В отдельном сайте nginx `/etc/nginx/sites-available/biomozg-n8n` настроены **только два точных адреса** с `alias` на соответствующие файлы. Корень проекта и папка secrets через них не публикуются. На этих адресах выключен access_log, включены no-store, nosniff, no-referrer и CSP без скриптов и форм.

Сохранённая конфигурация до размещения: `/srv/biomozg-instagram/backups/privacy-20261030T051131Z/nginx-before.conf`.

Исходники страниц хранятся в Git. Обычный `update_reshalo` сам не заменяет публичные юридические тексты. Изменение политики сначала согласуется владельцем, затем соответствующие HTML-файлы размещаются на сервере. Для замены только статического текста не нужен перезапуск ботов. Изменение nginx требует резервной копии, `nginx -t` и плавного reload.

## Работа с обращением об удалении

Оператор проверяет обращение из того же Instagram-аккаунта. Пароли, коды входа и документы для обычного запроса не нужны. При необходимости он приостанавливает автоответы в Telegram **/admin → 📸 Instagram · n8n** и поручает сопровождающему сервера удалить относящиеся к человеку данные из изолированной базы `/srv/biomozg-instagram/state/events.sqlite3`. Используется подтверждённый app-scoped ID, а не догадка по имени пользователя. Платёжная база Telegram-бота этой операцией не затрагивается.

После обработки оператор отвечает в исходном диалоге и отдельно учитывает более ранние резервные копии. Политика не обещает удалить исходный комментарий или переписку из Meta/Telegram: человек управляет ими средствами соответствующего сервиса.
